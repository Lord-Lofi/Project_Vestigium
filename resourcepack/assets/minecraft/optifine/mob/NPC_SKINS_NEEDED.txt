VESTIGIUM NPC CUSTOM SKINS — ARTIST BRIEF
==========================================

HOW THE SYSTEM WORKS
--------------------
Each NPC entity has a fixed custom name set in code. OptiFine's Random Entities
system matches that name and swaps in a custom PNG texture. Non-NPC villagers and
zombies are completely unaffected and keep their vanilla appearance.

TEXTURE SPECS
-------------
  Villager skins : 64×64 PNG, Villager UV layout
                   (same layout as assets/minecraft/textures/entity/villager/type/plains.png)
  Zombie skins   : 64×64 PNG, Zombie UV layout
                   (same layout as assets/minecraft/textures/entity/zombie/zombie.png)

NOTE ON PROFESSION OVERLAY
--------------------------
All code-spawned Villager NPCs are set to Profession.NONE. Minecraft still renders
a thin "unemployed" overlay on top of the base texture. Two options:
  A) Design skins that look intentional with the overlay visible (it's a faint plain robe).
  B) Include a transparent unemployed.png at:
       assets/minecraft/textures/entity/villager/profession/unemployed.png
     This suppresses the overlay for ALL unemployed villagers server-wide.

WORKFLOW WHEN READY
-------------------
1. Create PNG at the correct texture spec (Villager = 64×64, Zombie = 64×64).
2. Drop the PNG into the correct folder (same folder as the .properties file).
3. Reload the resource pack in-game. The NPC will immediately display the new skin
   for any client with OptiFine or an equivalent CEM-capable resource pack loader.

No server restart needed — resource pack changes are client-side only.
